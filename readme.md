# Ali Motasim — Portfolio

A static portfolio website built with semantic HTML, CSS, and vanilla JavaScript. It presents projects, technical skills, experience, and contact links in a responsive terminal-inspired interface.

## Run locally

No build step or dependencies are required. Open `index.html` directly, or serve the folder with any static web server.

## Project files

- `index.html` — page content and structure
- `style.css` — layout, responsive styles, and visual design
- `boot.js` — introductory boot sequence
- `background.js` — animated canvas background and terminal animation
- `script.js` — navigation, reveal, counters, and interaction behavior

The site is suitable for static hosting such as GitHub Pages. There is no build command, test suite, or environment configuration.
